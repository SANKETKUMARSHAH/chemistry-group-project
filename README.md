📌 Project Description

This project is a web-based molecular visualization tool built using Python.
It allows users to input SMILES notation and:

- Visualize molecules in 3D
- Calculate important chemical properties
- Analyze element composition

---

Features

- Interactive 3D molecular visualization
- Molecular weight & formula calculation
- Element detection and counting
- Atom-level details (atomic number, coordinates)
- Predefined compounds (dropdown)
- Custom SMILES input

---

Technologies Used

- Python
- Streamlit
- Open Babel
- Py3Dmol

---

Installation

1️⃣ Clone Repository

git clone https://github.com/SANKETKUMARSHAH/chemistry-group-project/tree/main
cd molecular-viewer

---

2️⃣ Install Dependencies

pip install -r requirements.txt

---

▶️ Run the Project

streamlit run app.py

Open in browser:

http://localhost:8501

---

Example SMILES

Compound| SMILES
Ethanol| CCO
Benzene| C1=CC=CC=C1
Water| O
Carbon Dioxide| O=C=O
Aspirin| CC(=O)OC1=CC=CC=C1C(=O)O

---

Output

The application provides:

- Molecular Weight
- Chemical Formula
- Number of Atoms & Bonds
- Element Composition
- Interactive 3D Structure

---

Important Notes

- Input must be in SMILES format
- Chemical formulas like "H2O", "CO2" will not work directly
